# تقویم سینما و سریال (Movie & TV Release Calendar PWA)

سامانه جامع و مدرن نمایش تاریخ انتشار فیلم‌ها و سریال‌های روز دنیا بر اساس تقویم شمسی (جلالی) و استاندارد پایگاه داده بین‌المللی TMDB، طراحی‌شده به‌صورت Progressive Web App (PWA) با قابلیت استفاده آفلاین، همراه با ورکر ابری Cloudflare Worker و پایگاه داده D1.

## معماری سیستم و فناوری‌ها

این پروژه در قالب یک مونوپروژه (Monorepo) متشکل از سه بخش مستقل پیاده‌سازی شده است:
- **`app/` (فرانت‌اند):** ساخته‌شده با Vue 3 (Composition API با script setup)، تایپ‌اسکریپت، Vite، ویو روتر، پینیا، Tailwind CSS v4، کتابخانه تقویم جلالی `jalaali-js`، موتور جستجوی آفلاین MiniSearch و IndexedDB (`idb`). این بخش با `vite-plugin-pwa` و Workbox دارای کش‌گذاری هوشمند لایه‌ای و عملکرد آفلاین کامل است.
- **`worker/` (سرویس لبه‌ای بدون نیاز به دیتابیس - Zero-D1):** کلودفلر ورکر با فریم‌ورک سبک Hono. وظیفه این بخش، پراکسی و کش مستقیم ۹۰ روزه تصاویر TMDB و کش ۳۰ روزه عناوین خارج از پنجره تقویم با استفاده از **Cloudflare Cache API** است. این بخش کاملاً مستقل، رایگان و بدون مصرف سهمیه دیتابیس یا کرون در کلودفلر عمل می‌کند.
- **`sync/` (برنامه سینک داده‌ها):** یک برنامه خط فرمان Node.js و TypeScript که هر ۱۲ ساعت توسط GitHub Actions اجرا شده، پنجره زمانی از ۱ سال قبل تا ۲ سال بعد را به برش‌های ماهانه تقسیم می‌کند و داده‌های اعتبارسنجی‌شده را در یک شاخه مجزا بنام `data` (به‌صورت orphan و تک‌کامیته با commit --amend) ثبت می‌نماید.

## نکات مهم حریم خصوصی و دسترسی شاخه data

> [!IMPORTANT]
> **نکته شفاف درباره دیده‌شدن ریپازیتوری (Repository Visibility):**
> اگر مخزن گیت‌هاب شما به‌صورت عمومی (Public) تنظیم شده باشد، محتوای شاخه `data` شامل فایل‌های JSON فیلم‌ها و سریال‌ها برای عموم کاربران اینترنت قابل دانلود و مشاهده است.
> **موازنه و بده‌بستان (Trade-off):** مخزن عمومی این امکان را می‌دهد که از ترافیک رایگان GitHub Pages و دقایق نامحدود GitHub Actions بهره‌مند شوید؛ در عین حال توجه داشته باشید که طبق قوانین TMDB شما نباید هیچ‌گونه تصویری را در ریپو ذخیره کنید و داده‌ها نباید بیش از ۶ ماه بدون رفرش باقی بمانند که برنامه سینک ما دقیقا این قوانین (رفرش دوره‌ای ۹۰ روز و حذف متادیتا بعد از ۱۵۰ روز) را تضمین می‌کند.

## متغیرها و سکرت‌های مورد نیاز

### سکرت‌ها (GitHub Secrets)
در مسیر `Settings -> Secrets and variables -> Actions` سکرت‌های زیر را ایجاد کنید:

1. `TMDB_READ_TOKEN`:
   توکن اعتبارسنجی خواندن API نسخه ۴ وب‌سایت TMDB (Bearer Token).
2. `CLOUDFLARE_API_TOKEN`:
   توکن API کلودفلر با دسترسی‌های `Workers Scripts: Edit` و `D1: Edit`.
3. `CLOUDFLARE_ACCOUNT_ID`:
   شناسه حساب کاربری کلودفلر (Account ID) قابل مشاهده در پنل کلودفلر.

### متغیرها (GitHub Variables)
در مسیر `Settings -> Secrets and variables -> Actions -> Variables`:

1. `VITE_BASE`:
   آدرس پایه دیپلوی گیت‌هاب پیجز. برای مثال اگر آدرس شما `https://username.github.io/movie-db/` است، مقدار آن را برابر `/movie-db/` قرار دهید (اگر از دامنه اختصاصی استفاده می‌کنید، مقدار `/` بگذارید).
2. `VITE_WORKER_URL`:
   آدرس ورکر مستقرشده در کلودفلر (مثلاً `https://movie-db-worker.yoursubdomain.workers.dev`).

## راهنمای گام‌به‌گام راه‌اندازی و دیپلوی

### گام ۱: دریافت توکن TMDB
1. در وب‌سایت [themoviedb.org](https://www.themoviedb.org/) عضو شوید.
2. به بخش `Settings -> API` بروید و یک درخواست کلید API ثبت کنید.
3. مقدار **API Read Access Token (v4 auth)** که یک رشته طولانی است را کپی کنید.

### گام ۲: راه‌اندازی و دیپلوی کلودفلر ورکر (بدون نیاز به دیتابیس)
در ترمینال خود وارد پوشه `worker` شوید و دستورات ساده زیر را اجرا نمایید:

```bash
cd worker
npm install

# ۱. لاگین در کلودفلر با ابزار رنگلر
npx wrangler login

# ۲. ذخیره سکرت توکن TMDB در کلودفلر ورکر
npx wrangler secret put TMDB_READ_TOKEN
# در پرامپت باز شده، توکن TMDB خود را پیست کنید و Enter بزنید.

# ۳. دیپلوی ورکر
npx wrangler deploy
```

> [!TIP]
> **عدم مصرف محدودیت دیتابیس و کرون کلودفلر (Zero Database & Zero Cron Usage):**
> هیچ دیتابیس D1 و هیچ کرون‌جابی برای این ورکر ایجاد نمی‌شود؛ کش لبه‌ای عناوین قدیمی و تصاویر مستقیماً با استفاده از Cache API خود کلودفلر انجام می‌شود.

آدرس خروجی ورکر (مثلاً `https://movie-db-worker.xxxx.workers.dev`) را یادداشت کنید.

### گام ۳: تنظیم سکرت‌ها و متغیرهای GitHub
به ریپازیتوری خود در GitHub بروید:
1. در `Settings -> Secrets and variables -> Actions`:
   - سکرت `TMDB_READ_TOKEN` را ثبت کنید.
   - سکرت `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` را ثبت کنید.
2. در تب `Variables`:
   - متغیر `VITE_BASE` را برابر با نام مخزن (مثلاً `/movie-db/`) قرار دهید.
   - متغیر `VITE_WORKER_URL` را برابر با آدرس ورکر کلودفلر (مرحله قبل) بگذارید.

### گام ۴: فعال‌سازی GitHub Pages
1. در تنظیمات گیت‌هاب به بخش `Settings -> Pages` بروید.
2. در بخش **Build and deployment**:
   - گزینه **Source** را روی **GitHub Actions** تنظیم کنید.

### گام ۵: اجرای اولین همگام‌سازی (First Sync)
1. به تب **Actions** در مخزن گیت‌هاب بروید.
2. گردش کار **Sync TMDB Catalog to Data Branch** را انتخاب کرده و دکمه **Run workflow** را بزنید.
3. این اکشن شاخه مجزای `data` را ساخته و کاتالوگ فیلم‌ها و سریال‌ها را دانلود و سازماندهی می‌کند.
4. پس از اتمام سینک، گردش کار **Build and Deploy PWA to GitHub Pages** به‌صورت خودکار اجرا شده و برنامه شما آماده استفاده می‌شود!

## توسعه و تست محلی

برای اجرای پروژه روی سیستم خود به شکل لوکال:

```bash
# نصب تمام وابستگی‌های مونوپروژه
npm install

# اجرای فرانت‌اند در محیط توسعه (با داده‌های آزمایشی آفلاین)
npm run dev:app

# اجرای تست‌های واحد فرانت‌اند
npm run test:app

# اجرای تست‌های واحد ورکر
npm run test:worker

# اجرای تست‌های واحد برنامه سینک
npm run test:sync

# اجرای سینک به‌صورت محلی (نیازمند تنظیم متغیر محیطی)
# در لینوکس / مک:
export TMDB_READ_TOKEN="توکن_شما"
# در ویندوز پاورشل:
$env:TMDB_READ_TOKEN="توکن_شما"
npm run --workspace=sync dev
```

## قوانین TMDB و انتساب JustWatch

طبق شرایط و ضوابط رسمی API پایگاه داده فیلم (TMDB Terms of Use):
1. عبارت الزامی زیر در صفحه درباره برنامه و پاورقی درج شده است:
   > *"This product uses the TMDB API but is not endorsed or certified by TMDB."*
2. لوگوی رسمی TMDB در بخش درباره قرار داده شده است و بر اساس ضوابط، اندازه آن از برند اصلی برنامه برجسته‌تر نیست.
3. اطلاعات پلتفرم‌های پخش آنلاین (Streaming Providers) متعلق به سرویس JustWatch است و انتساب رسمی آن با درج نام JustWatch صورت پذیرفته است.
4. برنامه فاقد هرگونه تبلیغات، کسب درآمد و مشتق‌سازی یا تغییر تصاویر TMDB است.
5. رکوردهای متادیتای عناوین طبق تعهد پس از خروج از پنجره و سپری شدن زمان مقرر (۱۵۰ روز) از مخزن پاکسازی می‌شوند.

## عیب‌یابی و پرسش‌های متداول

- **پرسش: بعد از اولین دیپلوی، تقویم خالی است.**
  - **پاسخ:** مطمئن شوید ابتدا گردش کار `Sync TMDB Catalog to Data Branch` در تب Actions یک‌بار به‌طور کامل و موفق اجرا شده باشد تا شاخه `data` ایجاد گردد.
- **پرسش: خطای ۴۰۱ در لاگ برنامه سینک نمایش داده می‌شود.**
  - **پاسخ:** توکن `TMDB_READ_TOKEN` نامعتبر است. دقت کنید که باید از توکن طولانی نوع Bearer (API Read Access Token v4) استفاده کنید، نه کلید کوتاه API Key v3.
- **پرسش: در مرورگر موبایل فونت فارسی نمایش داده نمی‌شود.**
  - **پاسخ:** فونت وزیرمتن به‌طور مستقیم در پوشه `public/fonts/` تعبیه شده و بدون وابستگی به اینترنت خارجی به‌طور کامل لود می‌شود. یک‌بار کش مرورگر را پاک کنید یا در تنظیمات برنامه دکمه «پاکسازی کامل کش» را لمس نمایید.
